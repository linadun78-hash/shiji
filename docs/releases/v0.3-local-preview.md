# 拾集 v0.3 Local Preview

这是拾集的第一个 GitHub 本地预览版，供开发者和早期测试者验证“小红书素材拾取、AI 整理、目的型报告、本地手册与导出”完整流程。

## 本次包含

- 主动拾取当前可见的小红书图文笔记。
- 将任务、素材、报告和手册保存在浏览器扩展本地存储中。
- Agent 1 单条素材整理，并保留可核验的原始引用。
- Agent 2 教程、旅行和通用目的报告。
- 按需保存到本地手册。
- PDF、PNG 和 JPG 报告导出。
- 用户自行配置 OpenAI 兼容的模型地址、模型名称和 API 密钥。

## 下载内容

- `Source code`：扩展、Python 本地服务、测试和文档。
- `xhs-task-material-collector-v0.3.0.zip`：只包含浏览器扩展运行文件。
- `xhs-task-material-collector-v0.3.0.zip.sha256`：扩展 ZIP 的 SHA-256 校验值。

扩展 ZIP 不能单独提供 AI 能力。第一次使用前，请阅读仓库中的 `LOCAL_PREVIEW.md`，安装 Python 依赖并启动 `127.0.0.1:8765`。

## 快速开始

```powershell
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
```

随后解压 `xhs-task-material-collector-v0.3.0.zip`，在 Chrome 或 Edge 的扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。

以上命令在源码解压后的项目目录执行。已有用户请先备份原扩展目录，将新运行文件更新到同一个安装目录后点击“重新加载”；不要卸载后重装或改换目录，以免原有手册无法继续访问。完整步骤见 `LOCAL_PREVIEW.md` 的“更新和回滚”。

## 校验下载文件

```powershell
(Get-FileHash .\xhs-task-material-collector-v0.3.0.zip -Algorithm SHA256).Hash.ToLowerInvariant()
Get-Content .\xhs-task-material-collector-v0.3.0.zip.sha256
```

两行结果应完全一致。

## 已知限制

- 这是本地预览版，不是 Chrome Web Store 的安装即用版本。
- 使用本地服务模式时，用户需要自行启动本地 Python 服务；直接模式无需 Python 服务，但依赖模型服务允许浏览器跨域请求。两种模式都由用户承担自己的模型 API 调用费用。
- 当前模型密钥配置界面只适合个人或受信任环境测试；直接模式的密钥保存在浏览器扩展本地存储，本地服务模式的密钥保存在本机应用数据目录。
- 当前仅支持小红书图文笔记，不支持视频笔记。
- 不包含云端账号、云端历史、额度、计费或自动同步。

## 隐私说明

扩展不会自动扫描或保存浏览内容。只有用户主动点击拾取并开启 AI 后，白名单素材字段才会经本机服务发送到用户自己配置的模型厂商。Cookie、登录密码、封面图片和小红书访问令牌不会进入模型请求。

发布到公开仓库前请勿提交 `.env`、真实 API 密钥、个人素材、日志或导出文件。
