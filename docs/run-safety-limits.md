# 本地验收运行限制

这些限制用于避免调试项目时重复启动服务、重复连接浏览器或让长时间模型请求失控。

## 服务进程

- 默认只使用 `127.0.0.1:8765` 一个后端端口。
- 启动前必须先检查监听进程；已有项目进程时只复用，不再 `Start-Process`。
- 临时端口只能用于隔离诊断，验收结束不得作为扩展的正式连接地址。
- 未确认 PID、命令行和工作目录前，不结束任何进程。

## 模型请求

- 一次只发送一个素材请求，不在一个浏览器/Node 调用中批量串行等待五条。
- 单条请求设置明确超时；完成结果立即写入本地匿名夹具或评估文档。
- 重新运行前先确认代理变量、后端健康状态和模型设置状态。
- 同一批素材失败后不自动无限重试，最多记录一次重试并停止等待。

## 浏览器与系统进程

- 浏览器连接只建立一次并复用；历史记录查询只允许按已知笔记 ID 精确过滤。
- 每次运行前后记录 `rundll32.exe` 数量；若数量在运行期间增加，立即停止继续自动化并转为只读诊断。
- 不使用绕过系统权限的命令，不批量结束 `rundll32.exe`，不把它们当作项目进程处理。
